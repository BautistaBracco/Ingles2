# Pull Request - Proyecto Colaborativo

## 📋 Descripción del Proyecto

Este repositorio contiene el trabajo colaborativo de nuestro grupo para la elaboración de una Pull Request (PR). 

## 👥 Integrantes del Grupo

- [Bautista Bracco]
- [Leandro Cuevas]

## 🎯 Objetivo

Desarrollar una Pull Request que incluya:
- Análisis de la propuesta seleccionada
- Organizador gráfico con movimientos retóricos
- Vocabulario clave identificado

## 📁 Estructura del Repositorio
```
.
├── README.md
├── movimientos-retoricos.png
├── terminos-clave.png
└── decisiones-grupo.md
```

## 📝 Documentos Principales

### 1. Organizador Gráfico
Ubicación: `/movimientos-retoricos.png`

Contiene la estructura de los movimientos retóricos identificados para nuestra PR.

### 2. Vocabulario Clave
Ubicación: `/terminos-clave.png`

Lista de términos técnicos y vocabulario específico necesario para la propuesta.


### 3. Acuerdos del Grupo
Ubicación: `/decisiones-grupo.md`

Registro de las decisiones y consensos alcanzados durante el proceso.
